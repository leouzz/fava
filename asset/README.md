# Put your Faba backups here

Everything in this folder except this file is ignored by git, so your audio never
ends up in the repository.

The minimum is the SD card dump: one `Kxxxx` folder per figure, containing
`CP01`, `CP02`… (with or without the `.MKI` extension). Decoded MP3 copies and the
official PDF booklets are optional and improve titles, covers, credits and lyrics.

To force a cover, add `covers/K0010.png` (jpg/webp also work).

See the main [README](../README.md#the-asset-folder) for the full layout.
